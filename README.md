TIRAS Clothes Factory is a sophisticated, premium web application built for modern textile manufacturing and retail. Designed with elegance and performance in mind, it serves as a comprehensive platform for browsing clothing catalogs, managing orders, and administrating product portfolios. It seamlessly blends a high-end customer experience with a powerful administrative dashboard.

## ✨ Features

- **Premium Responsive UI**: Stunning, modern design that looks perfect on desktops, tablets, and mobile devices.
- **Clothing/Product Catalog**: Browse the extensive collection of high-quality textile products.
- **Product Details**: Comprehensive views of individual products with detailed specifications.
- **Shopping Cart**: Seamless e-commerce experience for adding and managing products to buy.
- **Customer Authentication**: Secure Login & Register functionality for personalized experiences.
- **Checkout & Order Inquiry**: Streamlined checkout process with transparent order tracking.
- **Product Filtering & Search**: Quickly find the perfect items with robust search and filtering tools.
- **Portfolio & Services**: Discover our manufacturing capabilities and previous work.
- **Blog**: Keep up with the latest industry news and factory updates.
- **Contact Form**: Direct line of communication with the factory team.
- **Admin Dashboard**: Comprehensive control center for managing the entire platform.
- **Admin Authentication**: Secure access restricted to authorized personnel.
- **Content Management**: Full management capabilities for Products, Services, and Blog posts.
- **Contact Messages Management**: Review and respond to customer inquiries from the dashboard.
- **Responsive Navigation**: Intuitive, easy-to-use navigation across all devices.
- **Animations & Interactive UI**: Engaging micro-interactions and smooth transitions.
- **LocalStorage Persistence**: Reliable data retention for cart and user sessions.

## 🗺️ Pages & Routing

**Public Pages:**
- `Home` - The premium landing experience
- `Products / Catalog` - Full product listing
- `Product Details` - Specific item view
- `Portfolio` - Gallery of manufacturing excellence
- `Services` - Offerings and capabilities
- `Blog` - Articles and news
- `Contact` - Inquiry form and details
- `Login / Register` - Customer authentication
- `Cart & Checkout` - Shopping and order processing

**Admin Dashboard (Protected):**
- `Dashboard Overview` - Quick stats and metrics
- `Manage Products` - Add, edit, or remove catalog items
- `Manage Services` - Update service offerings
- `Manage Blog` - Publish and edit articles
- `View Messages` - Read contact inquiries

## 🛠️ Tech Stack

This project leverages modern frontend technologies for optimal performance and developer experience:

- **React** (UI Library)
- **Vite** (Build Tool)
- **JavaScript** (Core Language)
- **Bootstrap 5 & React Bootstrap** (Component Library & Layouts)
- **React Router** (Client-side Routing)
- **React Icons** (Iconography)
- **CSS** (Custom Styling & Animations)
- **LocalStorage** (State Persistence)

## 📁 Project Structure

A clean, modular architecture ensures maintainability and scalability:

```text
TIRAS-Clothes-Factory/
├── public/                 # Static assets
├── src/                    # Source code
│   ├── assets/             # Images, fonts, and global assets
│   ├── components/         # Reusable React components (Navbar, Footer, Cards, etc.)
│   ├── context/            # Global state management context
│   ├── data/               # Local data or mock data files
│   ├── hooks/              # Custom React hooks
│   ├── pages/              # Route-level components (Home, Contact, Admin, etc.)
│   ├── App.jsx             # Main application component & routing setup
│   ├── index.css           # Global styles and design tokens
│   └── main.jsx            # Application entry point
├── index.html              # HTML template
├── package.json            # Project dependencies and scripts
└── vite.config.js          # Vite configuration
```

## 🚀 Installation & Setup

To get this project running locally on your machine, follow these simple steps:

1. **Clone the repository** (or download the source code).
2. **Navigate to the project directory** in your terminal.
3. **Install the dependencies:**

```bash
npm install
```

4. **Start the development server:**

```bash
npm run dev
```

Your application should now be running at `http://localhost:5173`.
